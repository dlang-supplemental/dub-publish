== 0.4.1 — Progressive help on bare run (2026-08-06)

* Bare `dub-publish` (no args) shows embedded prohelp and exits 2 instead of defaulting to `register` and failing with git noise.
* `?` / `help` / `--help` use the prohelp progressive schema (`help.sdl`).
* `register` without a git repo prints a clean error (git stderr drained).
* Depends on `openshellorg/prohelp` `v0.2.1` via `deps/prohelp` (Windows `user32` link for clipboard).
* CI checkouts that tag into `deps/prohelp` before `dub build`.
