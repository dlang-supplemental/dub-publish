= Changelog

== 0.4.1 (2026-08-06)

* Bare invocation shows progressive help (prohelp) instead of failing as a default `register`.
* Git remote probe no longer prints `fatal: not a git repository` on stderr.
* Dependency: `openshellorg/prohelp` `v0.2.1` (`deps/prohelp`).

link:changelog-details/2026-08-06 - bare run prohelp.adoc[Details]

== 0.4.0 (2026-08-06)

* Windows release packaging: zip + `install.ps1` (User PATH under `%LOCALAPPDATA%\Programs\…`).
* GitHub Release workflow: stable on `v*` tags; **rolling** prerelease on `main`.
* Winget update CI (`dlang-supplemental.dub-publish`) gated on `WINGET_TOKEN` (first listing still manual).
* `dub-publish version` reports `VERSION` / release stamp.

link:changelog-details/2026-08-06 - windows release packaging.adoc[Details]

== 0.3.3 (2026-07-31)

* Drop `--password-stdin`; use `--password` / `-p`, `--password-file`, or `password.incoming`.

== 0.3.2 (2026-07-31)

* Default password drop file `password.incoming` under the config dir (Windows / macOS / Linux).
* `login --save-credentials` reads it when no CLI/env password is given, stores protected credentials, then deletes the drop file.
* `logout` also removes a leftover drop file.

== 0.3.1 (2026-07-31)

* `--password-file` for non-interactive / agent-friendly login (plus `--password` / `-p`).
* Interactive password prompt is opt-in via `--prompt-password` (no longer automatic).
* Docs: `-p` is not logged by the tool, but is visible in shell history and process lists.

== 0.3.0 (2026-07-31)

* Local credential store is no longer plaintext: Windows uses DPAPI (`credentials.v1`); other platforms Base64 + mode `0600`.
* `login` prompts for a password when missing (no echo); `--save-credentials` writes the protected store.
* `logout` clears stored credentials (including legacy plaintext `credentials` files).
* Legacy plaintext files are upgraded to the protected format on load.

== 0.2.1 (2026-07-31)

* `status` / register ingest poll use `/api/packages/:name/info` so a package registered with zero versions still counts as present (HTML and `/latest` 404 until the first tag is ingested).

== 0.2.0 (2026-07-31)

* Owner settings CLI: `logo`, `logo-delete`, `docs-url`, `categories`, `hooks`, `hooks-disable`, `repo`, `perms-add`, `leave`, `remove`.
* `hooks` regenerates the webhook secret, prints clean generic/GitHub/GitLab URLs (avoids dub-registry #614 malformation), and saves secret + URLs under the local config dir.
* `register` remains idempotent on "already registered" and refreshes metadata.

== 0.1.2 (2026-07-31)

* Treat "already registered" as success and refresh package metadata (`update`).
* Honor `--package` / `-n` on `register` for status and refresh targeting.

== 0.1.1 (2026-07-30)

* Unwrap JSON string quotes from `/api/packages/:name/latest` responses.
* Drop unused imports in `app.d` / `registry.d`.

== 0.1.0 (2026-07-22)

* Initial CLI: `register`/`publish`, `status`, `update`, `login`
* Session login against code.dlang.org (userman form) and package registration
* Detect repository URL from `git remote origin` and package name from `dub.json`/`dub.sdl`
* Credentials via flags, environment, or local config file
